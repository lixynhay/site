# 🌌 Интерактивная 3D Солнечная система

Реалистичная интерактивная модель Солнечной системы, созданная с использованием React, Three.js и TypeScript.

## ✨ Возможности

### 🪐 Планеты и объекты
- **8 планет** с реалистичными текстурами и параметрами
- **Карликовая планета Плутон** с текстурой "сердца" (Tombaugh Regio)
- **Солнце** с анимированной короной и солнечными вспышками
- **Спутники планет**: Луна, Фобос, Деймос, галилеевы спутники Юпитера, Титан и другие
- **Кольца Сатурна** из 15,000 частиц с делением Кассини
- **Астероидный пояс** из 5,000 частиц

### 🌠 Космос
- **34,400+ звёзд** 10 типов (красные карлики, сверхгиганты, нейтронные звёзды и др.)
- **Млечный Путь** из 35,000 частиц со спиральной структурой
- **35 галактик** трёх типов (спиральные, эллиптические, неправильные)
- **8 квазаров** с джетами
- **55+ туманностей** разных цветов и размеров
- **30 облаков космической пыли**

### 🎨 Визуальные эффекты
- **Северное сияние** на Земле (кастомный шейдер)
- **Пылевые бури** на Марсе (анимированные вихри)
- **Солнечные вспышки (CME)** с системой частиц
- **Атмосферное свечение** планет
- **Bloom эффект** для реалистичного свечения
- **Реальные наклоны орбит** планет

### 🎮 Управление
- **Орбитальный режим**: вращение, масштабирование, панорамирование
- **Свободный полёт** (WASD + мышь):
  - `W/A/S/D` - движение
  - `Space` - вверх
  - `Ctrl` - вниз
  - `Shift` - ускорение
  - `F` - переключение режима
- **Клик на планету** - просмотр информации
- **Hover эффект** - белая обводка при наведении

### 📊 Информация о планетах
- Диаметр и расстояние от Солнца
- Температура поверхности
- Гравитация
- Орбитальный период (год)
- Количество спутников
- Длина дня
- Тип планеты
- Подробное описание

### ⏱️ Масштаб времени
- Отображение текущей даты
- Регулировка скорости симуляции (0.25x - 10x)
- Пауза/воспроизведение

### 🛰️ Текстуры NASA
- Автоматическая загрузка реальных текстур NASA
- Fallback на процедурные текстуры
- Переключение между режимами

## 🚀 Технологии

- **React 18** - UI фреймворк
- **Three.js** - 3D рендеринг
- **TypeScript** - типизация
- **Tailwind CSS** - стилизация (Material 3 Expressive)
- **Vite** - сборка
- **postprocessing** - bloom эффекты

```bash

# Запуск dev сервера
npm run dev

# Сборка для production
```

## 🎨 Особенности реализации

### Процедурные текстуры
Все текстуры планет генерируются процедурно с использованием:
- Fractal Brownian Motion (FBM)
- Simplex noise
- Многослойный шум для деталей

### Шейдеры
Кастомные GLSL шейдеры для:
- Солнечной короны с вспышками
- Атмосферного свечения
- Северного сияния
- Пылевых бурь
- CME (корональных выбросов массы)

### Оптимизация
- Code splitting (three.js, vendor, app)
- Instanced rendering для частиц
- LOD система для звёзд
- Efficient buffer geometry
